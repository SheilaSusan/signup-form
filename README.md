# Sign-up Form

A sign-up form that validates like a real one, built with plain HTML, CSS and JavaScript.

**Live demo:** https://sheilasusan.github.io/signup-form/

## Features
- Fields: name, email, Mauritian mobile (+230 5XXX XXXX), password, confirm password
- Errors appear when you leave a field, not on the first keystroke
- Password strength meter (weak to strong)
- Confirm password must match
- Submit button is disabled until the form is valid, then shows a success message (nothing is sent)

## Run locally
Open `index.html` in a browser. No build step or dependencies.
